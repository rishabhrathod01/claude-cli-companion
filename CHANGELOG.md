# Changelog

All notable changes to Claude Code Context will be documented here.

## [0.0.1] - 2026-04-12

### Added
- `Cmd+L` / `Ctrl+L` — send native `@file:lines` reference to an open Claude terminal
- `Cmd+Shift+L` / `Ctrl+Shift+L` — same as above, auto-creates a Claude terminal if none is open
- Accept / Reject diff view when Claude modifies files on disk
